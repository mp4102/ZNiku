## 2. 本次固化的修复

1. 原生路径选择器进入独立进程；阻塞、取消、异常和 helper 退出不拖死 HTTP 服务。
2. 向导保留断线前本地草稿；重连不重放 mutation，过期选择/预览/分析响应不得串工程。
3. 第一步默认只要求素材组织方式、视频素材、工程名称、工程保存位置；工作数据默认在工程旁。
4. 第三步常驻片名、年份及四组重要处理参数；成片父目录默认取工程目录，可选改位置。
5. 输出位置由 Python 只读预览；精确切分等必填错误在下一步前显露并定位，不用隐藏高级区阻塞。
6. 对话框内键盘操作不被画布快捷键吞掉；回归复制/检查/显式 Submit、草稿与保存边界。
