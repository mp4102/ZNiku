## 2. 用户操作与默认值

第 3 步改名为“成片设置”。从上到下按以下顺序排列：

| 区域 | 内容与默认行为 |
| --- | --- |
| 成片名称与位置 | 常驻片名、四位年份；显示 Python 返回的完整成片目录 |
| 1 章节与分段 | 默认整片一章；可选精确帧/时间切分；章内单段时长沿用 1 分钟 |
| 2 画质增强 | 模型名、实际增强倍率、可选版本；沿用 Starlight Precise、1 倍 |
| 3 章节补帧 | 模型名、可选版本；沿用 Aion、固定两倍帧率；先合并同章增强段再补帧 |
| 4 成片编码 | GPU/NVIDIA 或 CPU 编码；沿用 GPU，不自动切换或引入新编码参数 |
| 其他选项（可选） | 修改/恢复成片父目录、片名子目录开关、覆盖许可、手动开发路径 |

处理参数不是隐藏的必经关卡；有有效默认值可以直接使用。模型版本可留空，外部模型名称/倍率须与
操作者实际提交产物一致，填写声明不会调用外部工具、自动放大或证明效果。预分章素材沿用素材章节，
不展示无效的二次分章选择；章内单段时长仍可调整。

新向导默认：`.zniku` 所在目录 → `片名（年份）` 子文件夹，例如 `Example Film (2026)`。
这里的工程目录不是 `.data`。改用专用工作数据磁盘不会顺带改变成片位置。无需再次选择成片父目录，
也无需提前创建片名文件夹。其他选项中可改为其他磁盘，或关闭片名子目录直接输出到父目录。
覆盖默认关闭，恢复工程目录不擅自修改片名、年份、布局或覆盖选择。

## 3. 唯一语义来源与检查时机

`publication-preview` 沿用现有路由和响应，`request` 严格接受两种互斥来源：

- `project_path`：Python 校验绝对 `.zniku` 文件目标并解析已存在父目录，文件本身可尚未创建。
- `output_root`：保留原有显式父目录行为。

未知字段、两种来源同时存在、缺少来源、非法类型、显式 null 失败关闭。不得推断 `.data` 或自动降级。
正式 expand 仍只接收既有 `PublicationRequest`；前端仅把本次 Python 返回的 `resolved_output_root`
绑定到精确工程路径，不在 TypeScript 切割路径、拼接成片目录或解析旧成片名。

目录自动预览采用 300ms 防抖，只展示结果、不抢焦点、不锁住表单。点击下一步始终重新检查，并在
顶层可选 `processing` 中提交当前处理字段。Python 复用既有 ChapterSelector、模型声明、倍率、段长
与编码器校验；无效时间、重复/倒序帧边界、模型空白等在创建工程及分析前拒绝。旧调用省略 processing
保持兼容。切分点是否超出真实媒体范围、媒体几何和实际兼容性仍须经素材分析确认，不假造预先证明。

处理错误以稳定服务错误码映射表单字段，不解析错误文案。必填缺项定位到常驻字段；自定义路径错误
自动打开“其他选项”并定位。恢复已有分析时若工程父盘不可用，停留设置步骤，允许另选成片父目录，
不退回不可编辑的建项步骤或丢失分析记录。

选择、目录预览、分析与确认工作流均不创建外部输出目录；仅实际输出节点按既有合同受控创建。
默认禁止覆盖及受保护源文件规则不变。旧 Python `PublicationRequest.layout` 省略值仍为 `direct`；
只有新向导显式选择 `title_subdirectory`。已有 Graph 不迁移、不改写；恢复向导如有正式输出声明，
沿用其显式父目录与布局，不从文件名反推片名年份，也不恢复旧系统选择句柄。

## 4. 并发与中断

自动目录预览、显式下一步、原生选择器、Graph 预览分别保留 token 和本地输入 epoch。输入变化、取消、
恢复默认、关闭或断线均撤销迟到响应资格。只读目录检查不触发创建/运行/输出，展开折叠本身不发送命令。
断线后保留表单，但不自动重播旧检查或不确定写入；恢复后须显式下一步重新检查。
