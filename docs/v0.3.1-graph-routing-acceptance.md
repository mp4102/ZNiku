## 1. 实际实现与所有权

| 项目 | 生产实现 | 不改变的边界 |
| --- | --- | --- |
| UI-B1 卡片 | 最多三项人类摘要；对象/数组显示设置数/项数；长名保留完整可访问名称；左右端口各有真实布局行 | 参数仍是同一 Python Schema 约束的数据；折叠不隐藏端口或错误 |
| UI-B2 追踪 | 鼠标/键盘端口直连强调，节点可追踪直连/上游/下游；保留箭头、完整来源/目标名称、ordered_many 顺序标签；交叉断口及背景描边 | 一条 Edge 仍绘制为一条独立 Edge，无总线合并或新汇合节点 |
| UI-B3 整理 | 实际卡片宽高、稳定 DAG 层级及原节点顺序排列；显式确认后应用；取消、Undo/Redo 与保存重开 | 只提交完整 `ui_position` 集合，不改参数、边、ordinal、选区、未应用草稿或执行结果 |
| UI-B4 路由 | 安全边距、坐标压缩通道、有界 A*、单视图缓存；非相邻障碍移入原路径也失效；出口/入口独立分轨 | 只消费矩形、真实锚点和 Edge 身份；路径/尺寸不写 Graph、StudioState 或 Run |
| UI-B5 时序 | 每帧最多一个最新请求，拖动轻量预算、落下完整预算；父级位置/卡片结构变化立即使旧测量失效 | 不创建新的保存、轮询、运行控制器；历史只读、原拖动缓存和单步手势保留 |

主要入口：`WorkflowNodeCard.tsx`、`CanvasGeometryObserver.tsx`、`use-canvas-routing.ts`、
`RoutedWorkflowEdge.tsx` 与 `studio/geometry/`。`StudioWorkspace` 仅接展示摘要和原有 `editAuthoring` 回调。
`applyLayoutPositions` 对缺失、额外节点及非有限坐标保留原 Graph；空/未测量/非法几何不由前端修补领域图。

小地图默认收起，通过左下“小地图”显式打开；开关不保存、不改变镜头或 Graph，避免窄窗口中常驻遮挡。
显式“适应画布”的最小缩放由 0.2 调至 0.02，以容纳大图；缩到概览不代表文字可编辑，仍可搜索或缩放到选区。
改变窗口尺寸不自动移动节点或抢占用户相机。

## 2. 测量、缓存与失败语义

测量读取锁定 `@xyflow/react@12.11.3` 的实际节点尺寸与 `handleBounds`，取 output 右外缘、input 左外缘及
各自端口行中心，与 ReactFlow 绘线锚点一致；不再使用按端口总数分配卡片百分比的旧公式。结构变化、
ResizeObserver、字体就绪/加载完成重新更新内部测量；只变化的进度/耗时文本不主动清空尺寸。
API 用途参见官方 [useUpdateNodeInternals](https://reactflow.dev/api-reference/hooks/use-update-node-internals)
与 [useStore](https://reactflow.dev/api-reference/hooks/use-store)，精确字段以锁定版本源码及实测为准。

缓存只留当前视图，签名包含实际尺寸/位置、两端口坐标、Edge 绑定和两侧 lane。旧、新障碍矩形与原路径
包围盒相交时失效，即使移动节点不是该边的端点。普通进度、选择、页签和历史分页不能排入新的几何任务。
暂缺测量时只取消旧请求，不对空投影求解或清缓存；真正空图通过非 null 的空测量正常清理路线，两者明确区分。
时间/工作预算降级不永久缓存；后续真实几何请求可重试。没有无界后台队列或在静止时反复自动忙循环。

当前/历史 Run 使用不同视图 key。组件同时核对同步 props 意图和实际测量，取消序号独立于浏览器取消帧：
被取消的 callback 即使迟到、同视图位置/结构已变而 observer 尚未回调、同 ID 换到旧 snapshot，都不能发布旧
路线或重新打开布局确认。渲染边还会核对实际四个端点坐标；不一致时立即用当前端点绘制暂时降级线。

| 预算 | 生产配置 | 超限行为 |
| --- | --- | --- |
| 路由规模 | 2,000 节点 / 3,000 边 | 降级显示，不拒绝合法领域 Graph |
| 单边通道网格 | 60,000 格 | `channel_budget` |
| A* 展开 | 单边 12,000 / 单次全图 60,000 | `work_budget` |
| 拖动 / 静止工作时间 | 8 / 32 ms；单边 4 / 12 ms | `time_budget`，协作式检查而非硬实时期限 |
| 交叉断口扫描 | 40,000 次比较，含包围盒早退出比较 | 停止额外扫描，保留每条边背景描边与方向/焦点 |
| 安全边距 / 断口半宽 | 12 / 5 画布单位 | 不更改端口绑定 |

`blocked_port`、`no_channel`、非法几何及各预算降级均为可见虚线，正常视图显示数量和“建议整理布局”。
降级允许穿过障碍但不计作避障成功；没有空路径、隐藏边、偷偷重连或移动节点。高级“连线诊断”只读显示
测量耗时、求解/缓存数、切片耗时和降级数，不把绘图预算写成媒体状态。

独立出口/入口 lane 按原 Edge 顺序安排；展开方向由对端相对 y 决定，同高统一向上。G03 的长共线段已消除，
但不承诺任意稠密/非平面图中段完全无共线或无交叉，也不引入拥塞系统、手动持久走线或新的可执行节点。

### 3.3 最终生产观测

Windows 本机、Chromium、1920×1080 / DPR 1、创作者密度，单 worker 串行采集；同一构建测试时没有并行
Python/媒体/单元负载。选择在两个可见节点之间真实切换并验证 Inspector 身份；参数每次只计 closed→open，
关闭在计时外；拖动先在计时外跨过启动阈值，随后每一个样本均验证实际坐标变化。

| 合成节点数 | 选择 p95 | 参数打开 p95 | 持续拖动 p95 | 观测的最长路由切片 |
| --- | ---: | ---: | ---: | ---: |
| 50 | 28.8 ms | 32.0 ms | 18.4 ms | 2.7 ms |
| 200 | 35.2 ms | 32.2 ms | 34.8 ms | 11.1 ms |

每项 20 个有效样本；50 节点满足 ≤150 ms。200 节点本次也较快，但不升级为同等 SLA。每个规模的拖动
包含启动/松手共 22 次求解，浏览器帧审计最大每帧一次；松手后稳定，无积压循环。选择/参数开关额外求解
为 0。41/196 条边整理后及拖后均成功避障、侵入扩张卡片数为 0；最后松手切换完整预算时 cacheHits=0
是有意完整重算，不冒充全量缓存命中。细粒度缓存另有纯 session 与真实 React 跨帧缺测量回归。

200 节点配 1,000 条合法空图历史：只请求 1 份按需详情，显式加载更早记录的 page limit 为 20；没有逐一
拉取全部历史详情，翻页不触发路由。合成 FFV1 完成记录在整理/Undo/Redo/重开后，Run、2 个 Artifact 及
latest_results 保持相等；首次布局保存恰好 1 次，含 Undo/Redo 共 3 次正常 authoring 保存。

默认 1/2/6/8/16 口均位于自身卡片内；16 口另查高级密度。G03 无长段共线，实际还保留一段 10 画布单位
短共线；200 节点也有中段共线，均保留在报告，不宣称全局消除。G09 的 blocked_port/channel_budget
明确显示虚线与提示，降级不计为成功避障。所有最终端点误差小于 1 CSS px，完整 M/L/Q 审计通过。

## 4. 复现与明确边界

在仓库根运行既有 Python 门禁；在 `apps/studio` 安装锁定依赖后运行：

```powershell
npm run typecheck
npm run test:run
npm run build
node --test preflight/geometry.test.mjs
node preflight/run.mjs
node --test e2e/batch-b-audit.checks.ts
npm run test:e2e
npx playwright test -c e2e/batch-b.config.ts
npm audit --audit-level=low
```

性能采集单 worker、无重试；50 节点仍按 p95 ≤150 ms 门槛，200 节点没有偷换成同等响应承诺。计时从浏览器
事件派发到两个 requestAnimationFrame，排除 Playwright 通讯/定位等待；不等于媒体处理速度或硬实时保证。
重采时不要并行运行全套 Python/媒体/单元测试影响性能数据。

原[实施前试验](v0.3.1-graph-preflight.md)和 A 截图保持冻结，只作改造前对照。B 不重写 Core/Runtime、
不改 `.zniku` 或合同版本、不引入新依赖；package/product 仍为 `0.2.0`、Project Service wire `0.3.0`、SQLite schema 4。
批次 C 的产品版本收敛、桌面候选、真实 Windows DPI/原生窗口、短真实媒体及首次创作者验收没有提前宣称完成。
本批源码不是新安装包，不会自动更新用户已经打开的旧页面/旧包，也没有重启用户服务。
