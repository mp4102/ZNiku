## 1. 实施结果

Phase 1 已在不改变 Graph／Runtime 语义的前提下建立可运行的展示与参数编辑层：

- 新增严格 Python `zniku.presentation` 合同，提供 exact `0.3.0`、`zh-CN` 的 category、node、parameter、
  port 与 diagnostic 模型；
- 内建 Presentation 覆盖 14 个 generic media definitions、9 个 AVEnhanceFlow v2.7.0 默认 definitions，
  动态 AtomicSplit 按当前具体 NodeDefinition 镜像真实端口；
- Project Service wire 成对升级到 exact `0.3.0`，新增独立只读
  `GET /api/studio/presentations`，Presentation 不进入 status、Project、Graph 或 Run snapshot；
- Studio 按 exact `type_id + definition_version` 连接 definition 与 Presentation；缺失或损坏的第三方
  Presentation 被隔离，节点仍使用正式 Schema 的通用表单；
- 大型 Workspace 已按 Project shell、Palette、Canvas、Inspector、Run center、Handoff center 与
  Diagnostics 拆出组件边界；
- Inspector 使用 Draft 2020-12 通用表单，覆盖 Phase 0 corpus 中的 object、array、string、integer、number、
  boolean、enum、const、default、边界、tuple、组合与条件关键字；
- 表单和“高级 → 原始参数”操作同一份 session `ParameterDraft`；非法 draft 不写回 Graph，用户必须显式
  “应用设置”，离开存在未应用内容的节点前必须明确放弃或留在当前节点继续处理。

## 2. 关键不变量

- Presentation 只提供文案、闭合 icon/control hint、排序、分组、picker hint 与既有 enum 的中文标签；模型
  不允许 required、default、范围、pattern、新 enum、executor、validator、argv、callback 或命令；
- 内建条目必须完整匹配 exact definition、全部顶层参数 pointer 和全部实际 input/output ports；任何漂移
  失败关闭；第三方错误逐条隔离并形成非阻塞 diagnostic；
- 参数合法性只由 NodeDefinition 的正式 JSON Schema 与 Python Graph Validator 决定；Studio AJV 只用于
  即时提示，遇 corpus 外 keyword 或无法安全渲染的局部会明确回退 raw JSON；
- 只有 Schema 明示的 `default` 或 `const` 可建立值；oneOf 首分支、`false`、`0` 和空字符串都不会被猜成
  业务默认值；
- 纯 Presentation 变化不进入 execution signature，不触发 stale；正式参数应用仍按既有规则使当前节点和
  下游结果 stale。
