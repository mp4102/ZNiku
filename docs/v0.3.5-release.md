## 1. 本版交付能力

- 自由编排媒体节点与 Schema 参数编辑；同一 Graph 保存、运行、显示进度和检查结果。
- 单一 AVEnhanceFlow 2.7.0 源准入；失败可显式选择外部修复候选，重新分析，不自动改写原片。
- 可选外部马赛克修复：格式化输入报告，选择无复制、检查通过后收纳、最后显式提交。
- 平均章数、精确时间、精确帧三种分章；章内独立分叶，默认最长 5 分钟、可设 1–60 分钟。
- 章级批量增强：每章一个多输出节点，支持多选、目录收件和分批补件，全部检查后显式提交。
- 增强先合章，再准备重叠上下文进行外部 FI，精确裁边后连续编码、封装原音轨并输出。
- 英文可读工程数据目录及独立处理轮次；已完成结果复用，不自动清除中间产物。
- 存储故障可见、保留成果的中断恢复；失败节点新 attempt 从头重跑，不恢复节点内部进度。
- 复制进度热路径修复及真实容量/速度显示；新建默认流程先验收最终目录候选，再发布正式名称，
  下游引用成果，不再复制第二份整片。旧工程保留原复制流程。

## 4. 公开资产与使用方式

  production 静态资源、FFmpeg 或外部 AI，不是双击 GUI。

开发运行使用源码中的 README 与 `uv.lock` / `apps/studio/package-lock.json`。本次不发布 PyPI、不安装到
用户环境，也不新选开源许可证；仓库现有版权与授权状态保持不变。

现有 Windows one-folder 捆绑包只保留本机使用：其工具、运行时及依赖的公开分发审阅尚未闭环，
不可把本机验收包直接上传为正式 Windows 资产。此限制不阻止源码 tag/Release，但应在下载页醒目标明。
未来公开 Windows 包需要单独补齐依赖许可/对应源码资料、干净环境构建和分发验证。
