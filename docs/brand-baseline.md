# ZNIKU 品牌与命名基线

- 状态：**已采纳的正式基线**
- 日期：2026-08-14
- 起始版本：`0.1.0`
- 权威范围：仅限品牌、产品名与代码标识；0.2.0 运行架构以
  [`graph-core-baseline.md`](architecture/graph-core-baseline.md) 为唯一权威

## 1. 核心身份

| 对象 | 正式名称 | 使用规则 |
| --- | --- | --- |
| 品牌 | `ZNIKU` | 面向用户的品牌名始终全大写 |
| 产品 | `ZNIKU Studio` | 图形化编排、工程管理与运行监控主界面 |
| 执行核心 | `ZNIKU Runtime` | DAG 调度、节点执行、运行状态与媒体副作用 |
| 扩展体系 | `ZNIKU Engine SDK` | 节点定义、adapter、开发工具与扩展入口 |
| GitHub 仓库 | `ZNiku` | 仓库名保持此大小写 |
| CLI / Python package | `zniku` | 命令、包名及代码命名空间使用小写 |
| 工程文件 | `.zniku` | ZNIKU Studio 工程文件扩展名 |

尚未实现的 CLI、Python package、工程格式、Runtime 与 SDK 不得伪装成现有能力，但所有新增设计和实现
必须使用以上名称，不再引入过渡品牌。

## 2. 标语

> **Flesh out every frame.**
>
> 让每一帧有血有肉。

英文标语是正式主标语，中文是正式释义。两者可以共同出现，也可以根据版面仅使用英文主标语。

## 3. 品牌语义

`ZNIKU` 保留个人风格元素 `Z`，并取日语“肉（にく／niku）”所表达的质感、生命力与身体感。
它对应产品使命：让素材从技术上的“可播放”，变成在纹理、运动与表现力上真正丰满的成品。

品牌视觉应保持专业、克制和电影感，可使用抽象帧、切面或 `Z` 形结构；不得依赖食物图标或露骨成人
意象表达产品定位。本文是仓库内品牌、产品名和代码标识的唯一命名权威，但不定义 Graph、Runtime 或
Engine 的领域与执行语义。
