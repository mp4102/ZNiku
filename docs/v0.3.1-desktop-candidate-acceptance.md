## 3. 实施与验证记录

### 3.1 交互收敛

- 删除/复制节点快捷键只在画布上下文生效。菜单、工具按钮、输入框不误触图修改；画布 Delete、Undo 和保存保留。
- 焦点恢复排除已卸载、disabled、hidden/inert、折叠 details 中不可见目标；模态忙碌时仍可把焦点留在对话框。
- 项目菜单和首页展示 npm 中的 `0.3.1 验收候选`，不在顶栏堆叠版本控件，也不把前端版本当作服务健康证明。
- 增加真实服务外部交接、失败恢复、存储迁移、CAS 保存冲突和真实迟到轮询回归；不新增测试专用生产接口。

五项生产 C 用例使用正式 DesktopServer、Project Service、SQLite、Graph 和 Runtime。原生目录选择器明确为
测试替身，媒体均为隔离合成 fixture：

| 用例 | 实际保护 |
| --- | --- |
| C1 外部收件 | 预览后文件换代精确拒绝；旧目标、源及上游字节不变；其他任务不被写入；已消费票据不能重放；明确检查后单次 Submit |
| C1 失败重试 | 已存在目标且禁止覆盖产生真实失败；仅移走并保留测试冲突物；新 attempt 从头执行，完成上游复用，Graph 未改 |
| C1 工程迁移 | 取消预览不复制；确认复制并重开后结果一致，原位置和原字节保留 |
| C2 保存冲突 | 未应用草稿和历史导航隔离；真实 `E_PROJECT_STORAGE_CONFLICT` 后取消重载不静默丢编辑或覆盖磁盘 |
| C2/C3 迟到响应与键盘 | 获取真实旧轮询响应，等新编辑保存确认后再释放；当前图和焦点不倒退；菜单 Delete 不删图；窄幅抽屉焦点可达 |

浏览器重放覆盖“已消费票据失效”，没有实等 300 秒 TTL；真实时钟过期、权限失败等仍由 Python 专项测试验证。
原 A/B 截图与指标保留，不用本次结果覆盖旧记录。

### 3.2 干净依赖与包一致性

以独立目录按既有 lock 安装 Python 3.12.13 和全部 29 个依赖，不升级依赖；独立 Node 目录 `npm ci` 安装
146 个包，audit 0 漏洞。从当前源码拷贝到干净 Node 目录构建，7 个 production 文件的集合和字节均与主构建一致。
页面入口为 `index-Dn8aHKVl.js`，主样式为 `index-CHvDav48.css`；HTML 描述不再硬编码旧产品版本。

wheel 包含 64 项，60 个包文件与源码一致，RECORD 的文件集合、SHA-256 和大小均有效。在另一独立环境中，
先按 lock 导出安装 10 个运行时依赖，再 `--no-deps` 安装 wheel，以 Python `-I` 导入全部 59 个模块，
确认版本为 `0.3.1` 且来自该环境的 site-packages，不借用源码目录或 editable install。

one-folder 使用干净环境 PyInstaller 6.22.2 构建。审计 1,188 个文件、532,591,894 字节，检查：

- 60 个 zniku 包文件与当前源字节一致；exe 内 PYZ 的 59 个模块及 desktop entry 与当前代码编译结果一致。
- 7 个生产资源与当前 dist 一致；FFmpeg/FFprobe 8.1.2 和原 LICENSE/README 的 4 份文件逐字节一致。
- 安装元数据仅显式收录 METADATA、WHEEL、top_level.txt，不再把开发安装路径元数据收进候选。
- 所有条目的名称、路径、大小写冲突和重解析点，以及整包已声明文本类型中的已知私人路径/秘密模式均检查。
  这不是通用秘密检测器；二进制第三方内容只做来源/字节一致性检查，不声称穷尽未知隐写或未知秘密格式。
- BUILD-INFO 明示 `source_kind=working_tree`、基点 `d33ce76`、构建时 dirty 和实际源码/资源指纹。
  不把基点 SHA 伪称为构建提交；提交后通过重新审计实际输入映射关联源码，包不自动上传 Git 或 Release。
